# FHX 的后花园

一个爱奇艺主题的互动宣传页概念演示。页面包含电视开屏、自动换台、影视分类、动态视觉与 VIP 权益展示。

在线预览：<https://haidarkhanuk3344-collab.github.io/FHX-backyard/>

## 使用

直接打开 `index.html`，或把本仓库的根目录发布为静态网站。无需安装依赖或构建。
