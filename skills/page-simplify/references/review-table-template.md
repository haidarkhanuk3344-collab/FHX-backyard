# 审查表与结果汇报模板

本文件是可选的交付模板。用户需要逐项审查、前后对照或表格时使用；简单修改可直接给出简短结果，无须每次加载或填表。判断与执行规则以 [SKILL.md](../SKILL.md) 为准。

## 审查表

| 位置 | 问题 | 处理 | 理由 |
|---|---|---|---|
| 页面、区域或具体元素 | 可观察的问题与影响；保留项可写其有效作用 | 保留 / 改写 / 合并 / 视觉校准 / 减弱 / 按需显示 / 删除 / 待核实 | 为什么采取此动作，以及需要保护的功能与设计价值 |

填写时按需增加行，只列与本次任务有关的项目。位置应能定位，理由应对应实际页面表现。**删除类建议必须写明移除损失评估**：是否影响必要信息、操作、构图、氛围或辨识度，依据是什么；不要只写“装饰太多”或“更简洁”。用途或真实性不明时标注待核实，不把推断写成已确认事实。

## 简短结果汇报

按任务需要填写以下内容，可合并成一段：

- **改动**：删减、合并、改写、校准或减弱了哪些内容。
- **保留**：核心内容、业务功能及主要设计巧思的保留情况。
- **验证**：实际检查了哪些页面、布局与交互，结果如何；仅查看截图或源码时说明范围。
- **未完成项**：尚未验证、待核实或受条件限制的项目；没有则省略。

审查表和结果说明用于交付，不放进产品界面。
